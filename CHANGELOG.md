# Changelog

## 0.1.0

- Standalone reference implementation accompanying the Streaming Sieve GMM methods post.
- NumPy-only online estimator with projected parameters, historical Jacobian gains, and full-history averaging.
- Normalized Hermite degree blocks zero through three; linear, quadratic, and exact exponential structural models.
- Reproducible identification, Jacobian-tracking, multivariate basis and nonlinear initialization studies.
- Examples, scientific equivalence checks, source provenance, and automated validation.
